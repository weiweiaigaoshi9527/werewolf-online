========================================================
  狼人杀 Online · 服务端（Windows x64）
  内置 Java 21 运行时，目标机无需安装 Java，解压即用。
========================================================

一、快速开始
--------------------------------------------------------
1. 把本文件夹解压到任意位置（路径别带特殊符号，建议 D:\werewolf-server）。
2. 双击  start.bat
3. 首次启动会自动生成自签 HTTPS 证书、初始化数据库，约 20~60 秒。
   窗口里会打印两行地址，例如：

     本机访问:   https://localhost:11111
     局域网访问: https://192.168.1.20:11111     <== 把这个地址发给玩家
     后台管理:   https://localhost:11111/admin   （首个注册账号即管理员）

4. 把「局域网访问」那个地址发给同一 WiFi 下的朋友，他们用浏览器打开即可开黑。
5. 停止服务：关闭那个黑窗口，或双击  stop.bat

注意：证书是自签的，浏览器首次打开会提示「不安全」，
      点「高级 → 继续访问」一次即可（每台设备各信任一次，之后不再提示）。


二、目录结构
--------------------------------------------------------
  start.bat               一键启动（含崩溃自动守护）
  stop.bat                停止服务（只停本目录的实例）
  make-cert.bat           重新生成自签证书（换网络/IP 变了时用）
  lan-ip.ps1              辅助脚本（取本机局域网 IP）
  voice-up.ps1            辅助脚本（拉起语音微服务 ASR/TTS）
  stop.ps1                辅助脚本（停止本目录的服务端与语音服务）
  runtime\                内置 Java 21 运行时
  werewolf-online.jar     服务端程序（Spring Boot 3.5 + 内嵌 H2）
  config\                 证书（首次启动自动生成 keystore.p12 与 werewolf-cert.cer）
  data\                   数据库：账号、战绩、房间数据 —— 删除即重置
  uploads\                玩家上传的头像
  logs\                   运行日志


三、可选参数（环境变量）
--------------------------------------------------------
  在 cmd 里先 set，再运行 start.bat：

    set WW_PORT=11222        &  start.bat    :: 换端口
    set WW_HEAP=2048m        &  start.bat    :: 加大 JVM 堆（人多时）
    set WW_HEAP=512m         &  start.bat    :: 减小堆（内存紧张时）
    set WW_BIND=192.168.1.20 &  start.bat    :: 只监听某个网卡

  默认：端口 11111，堆 1024m


四、让玩家不再看到证书警告（可选，体验更好）
--------------------------------------------------------
首次启动后 config\ 下会生成 werewolf-cert.cer。
把它发给玩家，双击 →「安装证书」→「本地计算机」→
选「将所有的证书都放入下列存储」→「受信任的根证书颁发机构」→ 完成。
此后浏览器就不再弹安全警告。


五、开机自启 / 后台常驻（可选）
--------------------------------------------------------
方式一（推荐，最省事）：任务计划程序
  1. Win+R 输入 taskschd.msc
  2. 创建任务 → 常规：勾选「不管用户是否登录都要运行」+「使用最高权限运行」
  3. 触发器：登录时（或启动时）
  4. 操作：启动程序 → 选本目录的 start.bat
  5. 再建一个「停止」任务指向 stop.bat（需要时手动跑）

方式二：把本目录做成 Windows 服务（需要额外工具如 NSSM，本项目不内置）


六、让外地玩家也能连（公网部署）
--------------------------------------------------------
局域网直接跑 start.bat 即可。要跨地互通，两种做法：

  A. 路由器端口映射：把外网端口映射到本机 11111（TCP），
     玩家连 https://你的公网IP:11111 。
     （家宽多为动态 IP，建议配 DDNS）

  B. 有 VPS/域名：用 Nginx 终结 TLS 再反代到本机 11111，
     做法见工程内 werewolf_app\DEPLOY-server.md 的 B 节。
     要点：反代必须给 /ws 与 /ws/voice 打开 WebSocket 升级头
     （Upgrade / Connection: upgrade），并把 proxy_read_timeout 调到 3600s，
     否则状态同步与语音会断连。

安全提醒：暴露到公网前，请先 set SSL_PASSWORD=强密码 并重跑 make-cert.bat。


七、语音（TTS / ASR）说明
--------------------------------------------------------
语音同传（真人说话 → 识别 → 用座位音色重新朗读；AI 逐句发声）靠两个本地 Python
微服务实现：SenseVoice（ASR，端口 5001）+ Kokoro（TTS，端口 5002）。

它们的运行时体积很大（Python + torch + 模型，共数 GB），所以【不随安装包分发】，
需要单独准备。start.bat 会自动按下面的顺序找语音目录，找到就拉起两个服务并启用语音：

  1) 环境变量 WW_VOICE_HOME 指定的目录
  2) 本服务端目录下的 voice\
  3) 服务端目录的上级目录下的 werewolf-voice\   （即和工程目录并排放）
  4) G:\werewolf-voice\                        （工程默认位置）

命中的目录里需要有：asr_service.py、tts_service.py、venv-asr\、venv-tts\、models\
判断成功的标志：启动窗口里会打印「语音同传: 已启用（...）」；找不到则会打印
「未检测到语音服务，将以纯文字模式运行」，功能上除麦克风外一切正常。

怎么准备语音目录（三选一）：
  A. 已经在本机装过（工程目录的 start.bat 跑过语音）：什么都不用做，
     第 3/4 条会自动命中，直接启动本包即可，已运行的 ASR/TTS 会被复用。
  B. 拷贝现成的语音目录：把 G:\werewolf-voice 整个复制过来，然后用
        set WW_VOICE_HOME=D:\你的路径
     再启动 start.bat。
  C. 全新安装：在工程根目录双击 voice\install_voice.bat（会自动装 Python 3.11、
     两个 venv 和模型，走国内镜像，约数 GB、视网速十几分钟到几十分钟），
     装好后本包会自动命中。

说明：
  - 纯文字模式完全可用；只有「浏览器麦克风 / 语音同传」需要语音服务。
  - 麦克风还要求 HTTPS（start.bat 默认就生成自签证书并走 HTTPS）。
  - stop.bat 只会停【本目录这次启动的】语音服务（记录在 logs\voice-pids.txt），
    不会去动别的实例已经在跑的 ASR/TTS。
  - 首次启动语音要加载模型，可能等几十秒；期间页面会显示「语音服务未就绪」，稍后自动可用。


八、常见问题
--------------------------------------------------------
Q: 双击 start.bat 一闪而过？
A: 说明启动前置检查失败。右键 start.bat → 编辑，或在 cmd 里执行
   start.bat 看具体报错（一般是路径不完整、缺 runtime\ 或 jar）。

Q: 提示端口被占用？
A: set WW_PORT=11222 & start.bat

Q: 玩家连不上？
A: ① 确认在同一局域网；② 本机防火墙放行该端口的入站
   （控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则），
   或首次运行时在弹窗里勾选「专用网络」允许。

Q: 忘了管理员账号 / 想清空数据？
A: 删掉 data\ 目录再启动即清空全部数据（谨慎），第一个注册的账号会成为管理员。

Q: 换了网络，浏览器提示证书名称不匹配？
A: 双击 make-cert.bat 重新生成证书，再启动服务。

Q: 能和工程目录里那份服务端同时跑吗？
A: 不能同端口。本包的 stop.bat 只停本目录的实例，不会误杀工程目录那份。
