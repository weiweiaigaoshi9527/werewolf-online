# 狼人杀 Online · 服务端（Windows / Android / Linux）交付说明

本目录提供**服务端本体**的三平台发行版：把原来只能靠工程目录 `start.bat` 跑的 Spring Boot 服务端，
做成了**手机可装的 APK**、**Windows 一键安装包 / 便携包**、**Linux 便携包**。

| 交付物 | 文件 | 大小 | 适合场景 |
|---|---|---|---|
| Windows 版服务端（安装包） | `werewolf-server-setup-1.0.0-win64.exe` | 89.9 MiB | 普通 Windows 玩家，双击装完就用 |
| Windows 版服务端（便携版） | `werewolf-server-1.0.0-windows-x64.zip` | 94.0 MiB | 免安装绿色版，U 盘随身带 / 常开机器 |
| 安卓版服务端 | `狼人杀服务端-android-arm64-v1.0.0.apk` | 123.7 MiB | 手机当主机，朋友连手机开黑 |
| Linux 版服务端 | `werewolf-server-1.0.0-linux-x64.tar.gz` | 98.7 MiB | VPS / 台式机 / NAS 常驻开服 |
| Windows 打包素材 | `win/` | — | 一键重建脚本 `build-win.ps1` + NSIS 脚本 + 包内脚本素材 |

| Linux 打包素材 | `linux/` | — | 启动脚本、systemd 安装器、说明、预置证书 |

## 一、Windows 版

### 1. 两种形态怎么选

| | 安装包（setup.exe） | 便携版（zip） |
|---|---|---|
| 使用 | 双击安装，开始菜单/桌面直接启动 | 解压后双击 `start.bat` |
| 需要管理员 | **不需要**（装到用户目录） | 不需要 |
| 写注册表 | 写卸载信息（可在「应用和功能」里卸载） | 不写 |
| 卸载 | 开始菜单 → 卸载，**保留账号/战绩/证书** | 直接删目录 |
| 适合 | 自己电脑长期开服 | U 盘带走、丢到常开的机器 |

两者内置的运行环境与行为完全一致。

### 2. 快速开始

1. 安装版：双击 `werewolf-server-setup-1.0.0-win64.exe` → 下一步 → 安装（默认装到 `%LOCALAPPDATA%\WerewolfServer`）；
   便携版：把 zip 解压到任意目录（建议纯英文路径，如 `D:\werewolf-server`）。
2. 双击 `start.bat`（安装版可从开始菜单/桌面快捷方式启动）。
3. 首次启动会**自动生成自签 HTTPS 证书 + 初始化数据库**，约 20–60 秒。窗口会打印：

```
============================================================
  狼人杀 Online 服务端（Windows）启动中...
  本机访问:   https://localhost:11111
  局域网访问: https://192.168.1.20:11111     <== 把这个地址发给玩家
  后台管理:   https://localhost:11111/admin   (首个注册账号即管理员)
  数据目录:   D:\werewolf-server\data
  停止服务:   关闭本窗口 或 双击 stop.bat
============================================================
```

4. 把「局域网访问」地址发给同一 WiFi 的朋友，浏览器打开即可开黑。
5. 停止：关闭那个窗口，或双击 `stop.bat`。`stop.bat` **只停本目录的实例**（按 jar 完整路径匹配），
   不会误杀工程目录、Linux/安卓等其它服务端。

### 3. 让玩家不再看到证书警告（可选）

首次启动后 `config\` 下会生成 `werewolf-cert.cer`。发给玩家 → 双击 → 安装证书 →
「本地计算机」→「将所有的证书都放入下列存储」→「受信任的根证书颁发机构」→ 完成。
之后浏览器不再弹安全警告。

### 4. 常用参数（环境变量）

```bat
set WW_PORT=11222        & start.bat     :: 换端口（默认 11111）
set WW_HEAP=2048m        & start.bat     :: 加大 JVM 堆（人多时；默认 1024m）
set WW_HEAP=512m         & start.bat     :: 减小堆（内存紧张时）
set WW_BIND=192.168.1.20 & start.bat     :: 只监听指定网卡
set SSL_PASSWORD=强密码   & make-cert.bat :: 重新生成证书并用强密码（公网暴露前务必）
```

### 5. 换网络 / IP 变了

双击 `make-cert.bat` 重新生成证书（SAN 会自动带上新的局域网 IP 与主机名），再启动服务即可。

### 6. 目录结构

```
start.bat          一键启动（含崩溃自动守护：后台点「重启」会以退出码 86 结束并被自动拉起）
stop.bat           停止服务（加 /y 可跳过结尾暂停，供安装/卸载程序调用）
stop.ps1           辅助脚本（停止本目录的服务端）
make-cert.bat      重新生成自签证书
lan-ip.ps1         辅助脚本（取本机局域网 IP）
runtime\           内置 Java 21 运行时（jlink 精简，约 61 MB）
werewolf-online.jar 服务端程序（Spring Boot 3.5 + 内嵌 H2）
config\            证书（首次启动自动生成 keystore.p12 / werewolf-cert.cer）
data\              数据库：账号、战绩、房间数据 —— 删除即重置
uploads\           玩家上传的头像
logs\              运行日志
使用说明.txt        包内说明（安装版安装后同目录可见）
```

### 7. 语音（TTS / ASR）——已接入，自动启用

`start.bat` 会**自动查找语音目录**，找到就拉起两个 Python 微服务（SenseVoice ASR:5001 / Kokoro TTS:5002）
并对游戏服务置 `VOICE_ENABLED=true`；找不到就退回纯文字模式（功能不缺，只是没有麦克风）。

查找顺序：`WW_VOICE_HOME` → 本目录 `voice\` → 上级目录 `werewolf-voice\` → `G:\werewolf-voice\`。
**本机已经装过语音**（`G:\werewolf-voice` 跑着 ASR/TTS），所以打包出来的服务端开箱就是语音可用的，
并且会**复用**已在运行的那两个服务，不会重复拉起。

判断成功的标志：启动窗口里 `语音同传:   已启用（...）`。

体积原因（Python + torch + 模型数 GB），语音运行时**不随包分发**。要在一台新机器上启用语音：
装好语音目录（可整个拷贝现成的，或用 `voice\install_voice.bat` 全新安装），
再用 `set WW_VOICE_HOME=<路径>` 指定，或放到服务端目录下的 `voice\`。
详见包内 `使用说明.txt` 第七节。

### 8. 公网部署

- **端口映射**：路由器把外网端口映射到本机 11111（TCP），玩家连 `https://你的公网IP:11111`（家宽动态 IP 建议配 DDNS）。
- **VPS + 域名**：用 Nginx 终结 TLS 再反代到本机 11111，做法见工程内 `werewolf_app/DEPLOY-server.md` 的 B 节。
  要点：反代必须给 `/ws` 与 `/ws/voice` 打开 WebSocket 升级头（`Upgrade` / `Connection: upgrade`），
  并把 `proxy_read_timeout` 调到 3600s，否则状态同步与语音会断连。

## 二、Android 版（APK）

### 1. 安装

1. 把 `狼人杀服务端-android-arm64-v1.0.0.apk` 传到手机（微信/QQ 传文件或 USB 复制皆可）。
2. 点击安装，系统提示「未知来源」时允许一次。
3. 要求 **Android 7.0 (API 24) 及以上、arm64-v8a**（近 8 年的手机基本都是）。

> ⚠️ 本 App 的包名是 `com.termux`（原因见第五节），因此**与官方 Termux 不能共存**：
> 手机上装了 Termux 的话需要先卸载，否则会提示「应用未安装/签名冲突」。

### 2. 首次初始化

打开 App，会提示解包内置的 Android 版 JDK 运行时：

- 解包体量约 **210 MB**，耗时 **1–3 分钟**，请插电、别锁屏；
- 建议手机至少留 **1.5 GB** 空闲存储（APK 124 MB + 运行时 210 MB + 服务端 60 MB + 数据库增长）。

### 3. 开始开服

1. 点 **「启动服务」**。首次启动要初始化数据库，约 20–60 秒；
2. 状态变成 🟢 运行中后，界面会显示：
   - 本机：`http://localhost:11111`
   - 局域网（发给玩家）：`http://192.168.x.x:11111`
3. 点 **「复制地址」/「分享地址」** 把这个地址发给同 WiFi 的朋友，他们用浏览器打开即可；
4. 点 **「打开控制台」** 可在 App 内直接进入游戏页面（也是后台管理 `/admin` 的入口）。

**谁是管理员**：第一个注册的账号自动成为管理员，浏览器访问 `http://<手机IP>:11111/admin` 进后台。

### 4. 让服务端在后台稳定运行

- 点 **「后台运行设置」** → 允许「忽略电池优化」；
- 在系统设置里给本 App **「允许后台活动 / 自启动」**；
- App 已内置前台服务通知 + 唤醒锁 + WiFi 锁，正常情况下锁屏也能继续当服务器。

### 5. 常用按钮

| 按钮 | 作用 |
|---|---|
| 启动 / 停止服务 | 拉起或优雅关停 JVM 进程（安卓通知栏也有一键停止） |
| 打开控制台 | App 内置浏览器打开本机服务端（自签证书自动放行） |
| 修复运行环境 | 重新解包运行时（**不会**删除账号/战绩数据） |
| 重生成证书 | 换网络后 IP 变了、想用 HTTPS 时重新生成自签证书 |
| 复制 / 分享地址 | 把局域网地址发给玩家 |
| 端口/内存 | 改监听端口（默认 11111） |

### 6. 关于 HTTPS（语音）

本 App **默认用 HTTP**，兼容性最好：**打字发言、AI 补位对局、房间、商店、战绩、回放、后台管理全部可用**。

只有**浏览器麦克风（语音同传）**需要 HTTPS。App 提供了 **「启用 HTTPS」** 勾选项：

- 勾选后会调用内置 `keytool` 生成自签证书（SAN 含本机局域网 IP）并以 HTTPS 启动；
- 但内置的 Android 版 JDK **缺少 EC 加密库 `libsunec.so`**，TLS 1.3 / ECDHE 可能协商失败；
- 因此 App 做了**自动降级**：若 HTTPS 起不来会自动改用 HTTP 重启一次；
- 若玩家连不上，请取消勾选 HTTPS。

### 7. 已知限制

| 限制 | 说明 |
|---|---|
| 与 Termux 冲突 | 包名复用，不能同时安装 |
| 语音同传不可用 | APK 里跑不了语音栈：语音微服务是 Python + torch + 数 GB 模型，没法塞进手机 App。故 Android 版固定为纯文字模式（打字发言、AI 发言、房间、战绩、回放全部正常） |
| HTTPS 可能不可用 | 运行时缺 EC 加密库，见上一节 |
| 仅 arm64 | 只打包了 arm64-v8a 运行时；32 位老机型需自行替换运行时（见第五节） |
| 内存占用 | 服务端 JVM 堆上限 512 MB（代码里 `ServerManager.DEFAULT_HEAP_MB`，可改） |

## 五、技术原理

### Android 上怎么跑 Spring Boot？

Android 的 ART 不能直接跑 Spring Boot 这种重度反射的 JVM 应用，必须自带一个
**为 Android（bionic）编译的完整 JVM**。本方案用的是 **Termux 的 `openjdk-21`（21.0.12）** 及其依赖闭包
（共 36 个 `.deb`，约 116 MB，含 `libc++_shared`、`libiconv`、`libandroid-spawn` 等）。

两个必须踩准的约束：

1. **`targetSdkVersion ≤ 28`**
   Android 10 起禁止不可信应用对自身私有目录内的文件调用 `execve()`（W^X）。
   只有 `targetSdk ≤ 28` 才保留旧行为。Termux 之所以能跑，也是因为它的 targetSdk 停留在 28。本 App 同理。

2. **`applicationId` 必须是 `com.termux`**
   Termux 的 JDK 是构建时把前缀 **硬编码**进二进制 `DT_RUNPATH` 的：
   `/data/data/com.termux/files/usr/lib/jvm/java-21-openjdk/lib:...`。
   而 Android 的应用私有目录正是 `/data/data/<applicationId>/`。
   把包名设为 `com.termux` 后，运行时被解包到 `/data/data/com.termux/files/usr`，
   与硬编码前缀**天然对齐**，不需要 `patchelf` 改 rpath。代价：不能与官方 Termux 共存。

### Windows / Linux 运行时怎么来的

| | Windows | Linux |
|---|---|---|
| 运行时 | **jlink 精简**（`tools/jdk-21/jmods`，21 个模块，解压 61 MB） | **Temurin JRE 21.0.12.1+1** 官方包（完整） |
| `keytool` | 从 JDK 的 `bin` 拷进 jlink 镜像（实测可用） | 未内置，改由 `start.sh` 调 `openssl` 生成 PKCS12 |
| 证书 | `make-cert.bat`（SAN 含主机名 + 局域网 IP，并导出 `.cer`） | `start.sh` 首次启动自动生成；也可删掉重生成 |

jlink 模块清单：

### 重新构建 Windows 包

一键脚本（会自动 jlink、组装、打 ZIP、编译 NSIS；缺 makensis 时只出 ZIP 并给出提示）：

```powershell
cd G:\狼人杀\服务端\win
powershell -ExecutionPolicy Bypass -File .\build-win.ps1
# 可加 -JdkHome / -NsisDir 指定路径；-SkipInstaller 只出便携版
```

产物输出到 `win\dist\`。脚本内各步骤等价于：

```
1. jlink 生成 runtime（见上表模块清单，--strip-debug --no-header-files --no-man-pages --compress=zip-6）
2. 拷 tools\jdk-21\bin\keytool.exe 进 runtime\bin
3. 组装 pkg\werewolf-server\{runtime, werewolf-online.jar, *.bat, *.ps1, 使用说明.txt, config/, data/, uploads/, logs/}
4. 打包：7z a -tzip -mx5 werewolf-server-1.0.0-windows-x64.zip werewolf-server
5. 安装包：在 pkg 目录执行 makensis install.nsi
```

注意两个坑：`.bat` 必须 **CRLF** 换行；`.ps1` / `.nsi` 含中文必须 **UTF-8 带 BOM**（`bat` 则不能带 BOM）。
另外 cmd 里 `for /f ('powershell ... ^| ...')` 的 `^|` 转义并不可靠，所以取 IP / 停进程都拆成了独立 `.ps1`。
