# 狼人杀 Online · 使用说明

局域网自用的网页版狼人杀，支持真人建房对战 + AI 补位，含完整主流玩法、账号成长、道具商店、战绩与回放。

技术栈：Spring Boot 3 + H2 内嵌数据库 + 原生 HTML/JS/CSS + WebSocket + OpenAI 兼容 AI。

---

## 一、启动

双击 `start.bat`（首次会自动构建、并生成自签 HTTPS 证书）。启动后控制台会打印访问地址：

- 本机：https://localhost:11111
- 局域网其他设备：https://<本机IP>:11111

**使用 HTTPS**：语音麦克风（getUserMedia）要求「安全上下文」，只有 `https://` 或 `localhost` 才能授权麦克风；用 `http://<局域网IP>` 访问时其他设备的麦克风会被浏览器拒绝。因此本游戏默认以 HTTPS 提供，`wss://` 语音/游戏通道随之启用。

- 证书是自签的，浏览器首次访问会提示「不安全/您的连接不是私密连接」，点「高级 → 继续访问」信任一次即可（每台设备各信任一次）。
- 证书在 `config/keystore.p12`，SAN 含 `localhost`、本机主机名、`127.0.0.1` 与当前局域网 IP。**若本机 IP 变了**，双击 `make-cert.bat` 重新生成证书后重启即可（否则用 IP 访问会有名称不匹配告警，用主机名/localhost 不受影响）。
- 想退回纯 HTTP（不需要麦克风时）：直接 `java -jar target\werewolf-online-0.1.0-SNAPSHOT.jar`（不加 `--spring.profiles.active=https`）即走 HTTP。

停止：关闭控制台窗口，或双击 `stop.bat`。

数据保存在项目目录 `data/`（H2 文件库），头像上传在 `uploads/`，删除 `data/` 即重置账号与战绩。

### 图形界面管理器（exe）

不想看黑窗口，可用服务端管理 GUI：`服务管理\服务管理.exe`（双击即用）

- **启动 / 停止服务**：一键拉起或优雅关停（等效 start.bat / stop.bat）；
- **语音微服务托管**：ASR/TTS 状态灯实时显示，可单独启停；**掉线自动重拉（守护）** 勾选后每 3 秒巡检，服务崩溃/被杀会在约 20 秒内自动恢复（经计划任务拉起，环境与双击一致）；
- **实时统计**：在线玩家、等待中/游戏中房间、进行中对局、注册用户、累计对局、运行时长、内存占用（每 3 秒刷新）；
- **实时日志**：服务端控制台输出实时滚动，同时追加写入 `logs/admin-gui.log`；
- **快捷入口**：一键打开游戏页面、打开数据目录；
- 首次启动若未自动定位工程，点右下角"重新定位"选择 `target\werewolf-online-*.jar`（会记住）；
- 命令行 `服务管理.exe --autostart` 可在打开界面后自动启动服务；
- 与 start.bat 一致：检测到 `config\keystore.p12` 时自动以 HTTPS 模式拉起服务端。

> exe 由 `jpackage` 打包、自带 Java 运行时；启动服务端时优先用自带 java，缺失时自动回退到项目内 `tools\jdk-21`。重建 exe：`javac -encoding UTF-8 -d target\admin tools\admin\AdminGui.java` 后打 jar，再执行 jpackage。

## 二、快速开始

1. **注册/登录**：进入登录页，切到"注册"填用户名+密码+昵称。
2. **AI 设置（可选）**：访问后台管理页 http://localhost:11111/admin （仅管理员，见第六节），在「AI API 配置」填 OpenAI 兼容服务的地址/Key/模型，勾选"启用"，点"测试连通"验证。
   - 想先不接真实模型试玩：地址填 `mock://local` 并启用，即可用内置离线假 AI 跑通整局。
3. **建房**：大厅点"创建房间"，得到 6 位房间号，把它告诉朋友。
4. **加入**：朋友在登录后的首页点"房间号加入"，输入房间号。
5. **补位**：人数不足时房主点"🤖补位 AI"逐个添加 AI 玩家（AI 完全伪装成真人）。
6. **开局**：全员准备后房主点"开始游戏"。

## 三、玩法（标准扩展集 11 角色 + 自定义板子）

- 狼阵营：狼人、狼王（被放逐可开枪）、白狼王（可自爆带人）
- 神职：预言家、女巫、猎人、守卫、白痴、乌鸦、禁言长老
- 平民：村民

流程：夜晚（守卫→狼人→女巫→预言家→乌鸦→禁言长老）→ 天亮死讯 → 首日警长竞选（1.5 票、警徽流）→ 依次发言 → 放逐投票（平票 PK）→ 开枪 → 遗言 → 翻牌判定 → 循环。胜负判定：狼全灭则好人胜；**存活狼人数 ≥ 其余存活玩家数即狼人胜**（绑票/屠城）；屠边板另有“神全灭或民全灭狼胜”。拟真倒计时，超时自动过。

## 四、账号与商店

- **等级/经验/金币**：完赛、胜利、存活、MVP 均有金币与经验奖励，达到经验自动升级。
- **金币流水**：个人主页可查看每一笔收支。
- **装扮**：头像（可上传自定义，自动裁剪）、头像框、称号、昵称颜色，在"商店"用金币购买，"我的主页→背包"穿戴，在对局与房间内可见。
- **功能道具**（对局内生效，每局限带 1 件）：查杀卡、护盾、沉默卡、双倍积分卡。在背包点"携带"带入下一局。

## 五、战绩与回放

- 个人主页"战绩统计"：总场次、胜率、狼人/好人胜率、最近对局。
- 点任意一局"回放"：上帝视角时间轴，可播放/暂停/单步/倍速，含夜晚全部行动与身份揭晓。

## 六、后台管理（/admin）

独立后台页：浏览器访问 **https://localhost:11111/admin**（与玩家界面分开）。**仅管理员可进入**，服务器对所有 `/api/admin/**` 强制鉴权（未登录 401、非管理员 403）。

- **谁是管理员**：第一个注册的用户自动成为管理员；也可在 `application.yml` 配 `admin.bootstrap-usernames`（或环境变量 `ADMIN_BOOTSTRAP_USERNAMES`，逗号分隔）在启动时把指定账号置为管理员；已有管理员可在「用户管理」里把别人设为/取消管理员。若系统里一个管理员都没有，启动时会兜底把最早注册的用户提为管理员。
- **系统状态**：版本、在线人数、房间数、进行中对局、注册用户、AI 是否启用、ASR/TTS 健康。
- **AI API 配置**：OpenAI 兼容地址/Key/模型/思考深度/温度/超时/重试/并发/启用 + 连通测试（存数据库，重启保留）。
- **语音服务配置**：ASR/TTS 地址与总开关、每座位音色、逐句节奏、VAD、匿名伪装昵称/头像/颜色；保存即时生效并持久化（重启保留）。
- **用户管理**：搜索、设为/取消管理员、封禁/解封（封禁即踢下线且不能登录）、重置密码。

## 七、AI 说明

- AI 通过后台配置的 OpenAI 兼容接口驱动，具备完整对局上下文与全功能操作（夜晚刀/救/毒/验、发言、投票、开枪等）。
- 服务器强制**信息隔离**：每个 AI 只能看到其身份有权知道的信息，狼人 AI 会隐藏身份、预言家 AI 会择机跳身份。
- AI 调用失败/超时会自动降级为合法随机动作，保证对局永不卡死。
- 思考深度分低/中/高三档（影响推理与 token 预算）。

## 九、常见问题

- **端口被占用**：改 `src/main/resources/application.yml` 的 `server.port` 后重新 `build.bat`。
- **AI 不发言/秒过**：进 `/admin` 的「AI API 配置」确认已启用且"测试连通"通过；未启用时 AI 座位走随机代打。
- **进不去后台**：`/admin` 仅管理员；用最早注册的那个账号登录，或配置 `ADMIN_BOOTSTRAP_USERNAMES` 后重启。
- **忘记账号**：删除 `data/` 目录重启即清空所有数据（谨慎）。

## 十二、当前状态快照（2026-10-02）

### 架构与客户端
- **后端**：Spring Boot 3.5 + H2 文件库（`data/`）+ 原生 WebSocket（`/ws` 状态、`/ws/voice` 二进制语音）+ OpenAI 兼容 AI。前端为单页 `static/`（app.js / style.css / index.html / i18n.js / voice.js）。
- **语音微服务**：SenseVoice(ASR，端口 5001) + Kokoro(TTS，端口 5002)，位于 `G:\werewolf-voice`（python=py311）。`start.bat` 会自动拉起并置 `VOICE_ENABLED=true`；未就绪时自动退回纯文字。
- **客户端 = WebView 套壳**：
  - **桌面**：Electron 工程 `G:\wwelectron`（`main.js` 加载实时网页；`setup.html` 提供「服务器地址」输入框，首次运行手工填写并测试连接；信任自签证书；放行麦克风）。用 `@electron/packager` 打包。
  - **移动/通用**：PWA（`static/manifest.json` + `sw.js` 网络优先 + `icons/`），浏览器「安装到主屏幕」即可，离线可开。
  - 旧的 Flutter 工程 `werewolf_app/` 已降为 **legacy**（保留参考，不再作为主客户端）。
  - Electron 加载的是服务器上的实时网页，**后端/前端改动自动生效，一般无需重打包客户端**。

### 运行 / 构建 / 验证
- 启动：双击 `start.bat`（HTTPS，profile=https，keystore `config/keystore.p12`）。停止：`stop.bat`。
- 构建：`build.bat`（`mvn -DskipTests package`，用 `tools/jdk-21` + `tools/apache-maven`）。**静态资源打进 jar，改前端必须重新 package + 重启。**
- 验证：`node -c` 查 JS 语法；`java -cp target/classes com.werewolf.rules.sim.Simulate` 跑规则引擎（应「19 通过 0 失败」）；Edge headless 截图脚本 `shot.ps1`。
- 坑：`npm` 装 electron 卡在 GitHub → 设 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`；PWA manifest 必须用 `.json`（`application/json`），用 `.webmanifest` 会被当 `octet-stream` 导致装不上；Flutter/CMake 等原生构建路径含中文会失败，须复制到纯 ASCII 路径（`G:\wwapp`）再 build。
