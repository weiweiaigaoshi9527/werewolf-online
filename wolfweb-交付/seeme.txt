  狼人杀 Online  (Werewolf Online) —— 项目介绍
  Moonlit Village · A self-hosted Werewolf game with real-time play,
  AI villagers & voice rooms
══════════════════════════════════════════════════════════════════

【一句话介绍】
  一套可自部署的"狼人杀"多人在线对战平台：网页实时对局 + 会"说人话"的
  AI 玩家 + 语音房同传 + 完整社区体系（好友/组队/观战/商城 VIP/排行榜/
  论坛）+ 管理后台，支持 Windows / Linux / macOS / Android / iOS / 网页
  六端互通，并提供可一键安装到虚拟主机的 PHP 版本（本目录）。

────────────────────────────────────────────────
一、项目特点
────────────────────────────────────────────────

1. 实时对局引擎（事件溯源架构）
   · 全局唯一不可变事件流（seq/阶段/天数/类型/行动者/目标/详情），
     每一步操作可审计、可回放、可回溯；
   · 白天发言 → 投票 → 放逐 → 遗言 → PK 谈判，夜晚守卫 → 狼刀 →
     预言家验人 → 女巫双药 → 乌鸦抹黑，全流程状态机驱动；
   · 警长竞选、平票 PK、猎人开枪、白狼王自爆等进阶规则完备；
   · 断线重连不丢状态，严格超时自动补位，杜绝"卡死局"。

2. 会"说人话"的 AI 玩家（本项目最大特色）
   · LLM 决策 + 规则托管双轨：配置了大模型时 AI 真正"思考"发言；
     未配置时自动降级为拟人托管（带 1.2~3.4 秒拟人思考停顿）；
   · 三层反雷同体系：
       - PhraseDedup：n-gram Jaccard / 包含度相似度检测，AI 不会
         重复自己与他人说过的话；
       - Humanizer：8 套语癖人设池（口头禅、语气、断句风格）；
       - PromptLibrary：提示词级反雷同指令注入；
   · AI 之间互相独立、口癖各异，旁观几乎分不清是真人还是 AI。

3. 语音房同传
   · SenseVoice ASR（语音转文字）+ Kokoro TTS（文字转语音）双引擎；
   · SpeechDirector 全房串行节奏调度：谁在说话、旁白何时插入、
     遗言播完才进下一阶段，系统与旁白永远在同一"频道"；
   · 真人麦克风语音自动转文字上屏，AI 发言自动真人声朗读，
     语音与文字双通道任意切换。

4. 视觉体系：13 套主题 + 7 种强调色
   · 月夜蓝、暗夜紫、樱粉浅色、青瓷、墨玉、鹅毛雪、暖沙、琥珀…
     全部 CSS 令牌化，一键切换实时生效；
   · 界面 2.0 应用外壳：顶栏 + 侧边导航 + 单滚动容器，
     手机端底部导航、桌面端侧栏，三端互适；
   · 新手引导、快捷键、@补全、投票可视化进度条、结算大事记、
     计时环等体验细节全套。

5. 完整社区与运营体系
   · 双人组队（与好友同阵营开黑）、跨房邀请、一键快速开局；
   · 观战模式（不泄露底牌）、出局自动翻牌、死者身份可见；
   · 好友系统（消息红点提醒、私聊）、排行榜、论坛、商城 VIP
     （开通/续费）、个人档案（emoji 头像框）、更新日志；
   · 管理后台：功能开关（房间内/大厅功能随时启停）、显示配置
     （页面最大高度等）、用户管理（封禁/赠 VIP/重置密码）、
     房间管理、公告与更新日志编辑。

6. 信息安全与公平性
   · 全自动 120 轮状态接口轮询测试：0 泄露（全知视角仅结算时开放）；
   · 底牌/神职信息服务端逐座位裁剪，越权请求直接拒绝；
   · 密码哈希存储、会话票据、CSRF 防护、管理员接口独立鉴权。

7. 六端互通
   · 网页端（PWA 可安装到桌面/主屏）；
   · Windows 安装包（NSIS）、Linux 压缩包已上架内置下载页；
   · macOS（dmg 工程）、Android（Capacitor 工程，含麦克风权限
     与网络安全配置）、iOS（Xcode 工程）工程就绪；
   · 桌面/手机/网页三端同账号互通，房间号即邀请码。

8. 部署友好
   · 服务端为 Spring Boot 单可执行 JAR，内嵌 H2 数据库，零外部
     依赖，java -jar 一条命令起服务；
   · HTTPS 开箱即用（内置自签证书，SAN 覆盖 localhost/主机名/
     局域网 IP/DDNS 域名，有效期 10 年），证书 .cer 可一键导入
     受信任根实现浏览器无警告访问；
   · 另提供"虚拟主机版"（PHP + MySQL/SQLite）：带完整安装向导，
     上传解压即可在任意 PHP 虚拟主机上跑起完整游戏。

────────────────────────────────────────────────
二、性能与关键配置参数
────────────────────────────────────────────────

  · 对局推进看门狗：AI 看门狗时限 = 模型有效超时 × (重试次数 + 1) + 15s，
    保证 LLM 正常返回前绝不抢先代打；
  · 托管拟人节奏：思考停顿 1.2~3.4s 随机 + 旁白余量累加，
    单步上限 25s，杜绝 AI"秒发言/秒投票"的机械感；
  · TTS 播报时长估算：实测 Kokoro 267ms/字，估算公式 = 205ms 头部
    + 900ms 基础 + 字数×估速 + 120~240ms 间隙，旁白与操作零漂移；
  · 语音串行调度：全房 roomLock 串行 + paced 播报，杜绝"别人没说完
    就被截断"；
  · 会话策略：保留登录 7 天可选（记住登录/公共设备两档）；
  · 数据库：H2 内嵌（文件模式），关闭即落盘，备份=拷一个文件；
    虚拟主机版使用 MySQL 或 SQLite（PDO），免装任何扩展服务；
  · 资源占用：空载 RSS ≈ 400MB（Java 版，含语音微服务另计约 300MB，
    可按需停用），1 核 2G 云主机即可流畅跑 5~8 个并发房间；
  · 网络：单 WebSocket 长连接承载全部状态推送，弱网自动降频轮询。

────────────────────────────────────────────────
三、技术栈
────────────────────────────────────────────────

  服务端    Java 17 · Spring Boot · WebSocket (STOMP) · H2 Database
  规则引擎  自研事件溯源 GameEngine（不可变事件流 + 状态机）
  AI 层     LLM 决策编排 · PhraseDedup 去重 · Humanizer 语癖 · AutoPolicy 托管
  语音      Python 微服务 ×2（SenseVoice ASR :5001 / Kokoro TTS :5002）
  前端      原生 HTML/CSS/JS（零框架）· CSS 令牌主题系统 · hash 路由 SPA
  客户端    Electron 33（Windows/Linux/macOS）· Capacitor 6（Android/iOS）· PWA
  打包      electron-builder 26 · Maven Shade
  虚拟主机版 PHP 7.4+ · PDO (MySQL/SQLite) · flock 并发锁 · 懒调度 tick

────────────────────────────────────────────────
四、虚拟主机版（本目录 wolfweb）包含
────────────────────────────────────────────────

  ✓ 安装向导（install.php）：五步完成部署
      1) 环境体检：PHP 版本/扩展/磁盘/目录权限/数据库驱动逐项检查；
      2) 自动安装依赖与补丁：建表、种子数据、补丁版本迁移一键完成；
      3) 数据库配置：MySQL / SQLite 二选一，在线测连；
      4) 账户与管理员：站长账号 + 管理员权限一步到位；
      5) 网站设定：站名、主题、板子配置、功能开关默认值，
         附自签 HTTPS 证书生成指引；
      安装完成后自动上锁，防重装攻击。

  ✓ 与主项目功能一致：大厅/房间/对局（12 神职自由配板）/AI 托管
    （含反雷同）/双人组队/观战/好友/排行榜/论坛/商城 VIP/更新日志/
    管理后台（功能开关·显示配置·用户管理·房间管理）；
  ✓ 更新系统：版本号 + 补丁迁移表，后台一键"检查更新/应用补丁"；
  ✓ 备份系统：后台一键备份（SQL 全量导出到 storage/backups）+ 下载；
  ✓ 插件系统：plugins/ 目录即插即用（plugin.json 声明钩子），
    内置示例：llm_speaker（接大模型让 AI 真开口）、
    voice_bridge（外接 ASR/TTS 语音桥）、battle_report（结算战报）；
  ✓ 虚拟主机兼容性：无 WebSocket 依赖（懒调度 tick 推进对局）、
    无 exec/shell 依赖、flock 并发保护、纯 PDO 预处理防注入。

────────────────────────────────────────────────
五、快速开始
────────────────────────────────────────────────

  【主项目（推荐有服务器/云主机）】
    1. 安装 Java 17+，运行：
       java -jar werewolf.jar --spring.profiles.active=https
    2. 浏览器打开 https://你的IP:11111 ，将 config/werewolf-cert.cer
       导入"受信任的根证书颁发机构"即可无警告访问；
    3. 注册第一个账号即为站长（自动管理员）。

  【虚拟主机版（任意 PHP 空间）】
    1. 把本目录全部文件上传到虚拟主机网站根目录（或子目录）；
    2. 确保目录可写（storage/ 会自动创建）；
    3. 浏览器打开 http://你的域名/install.php，跟随五步向导完成安装；
    4. 安装完成后用站长账号登录，进入"管理后台"配置功能开关与插件。

  【在线试玩（无需部署，直接体验）】
    在任意已部署实例上开一局即可
    （6 人快局演示：2狼/预言家/守卫/2村民，你是 1 号，其余 AI 托管）
