# 狼人杀客户端 · 安装与说明

版本 **1.4.0**（五端 Flutter 原生客户端 + Web 静态站点）。服务端端口是 **11111**（HTTPS 自签证书），
不是早期的 8080——填地址时注意。

> ⚠️ **1.3.0 已废弃并从本目录删除**：那个版本的 3D 视角只有引擎、没有接入对局页，功能实际点不开。
> 请使用 **1.4.0**。

## 本次新增（1.3.0 → 1.4.0）

- **3D 视角真正可用**：对局页顶栏的 3D 按钮，把「围坐圆桌」渲染成 3D 场景——
  11 套角色造型（狼影 / 女巫 / 骑士 / 弄臣 / 王族 / 死神 / 霜灵 …）、圆桌与提灯、
  星空、昼夜光照；可拖拽旋转、滚轮或双指缩放，右下角有「重置 / 远景 / 近景」快捷视角；
  发言者会有地面光环并转身面向镜头，出局玩家立起墓碑，头顶显示名牌与发言气泡。
  开关记在本机（`ww_mode_3d`），下次进对局自动恢复。
- **观感增强**：地面阴影改为三层柔化椭圆、角色加边缘光（Fresnel）、头/躯干/披风提高曲面精度；
  顺带修掉「桌面缺一半」的共面排序缺陷。
- **新增 Web 版**：`werewolf-client-1.4.0-web.zip` 是纯静态站点，解压后放到任意静态服务器即可。
- **新增 iOS 版**：`werewolf-client-1.4.0-ios-unsigned.zip` 是**未签名**的 `Runner.app` 归档，
  无开发者证书无法直接装真机（见下方 iOS 说明）。

> 说明：3D 是**自研的纯 Dart 软件渲染**（不引入任何第三方 3D 引擎），因此是平片着色、
> 没有实时阴影与 PBR 材质——观感比网页端的 WebGL 版朴素，但零依赖、各端一致、离线可用。
> 对局随时可再点一次按钮切回原来的 2D 座位条。

## 本次新增（1.2.0 → 1.3.0）

对齐网页端的平台相关能力，四项都在客户端内可直接用：

- **外观与主题**：大厅右上角 🌙 面板，13 套主题 + 7 种强调色 + 字号 / 密度 / 动效 /
  背景亮度 / 自定义背景；热键 `T` 随机主题、`D` 切换密度。
- **多语言**：🌐 语言按钮，中文 / English / 日本語 / 한국어 / Русский 五种，
  选择即刻生效并记在本机（键名 `ww_lang`，与网页端一致）。
- **背景音乐**：大厅右上角 🎵 面板，可添加**本机**多首 MP3、上一首 / 播放暂停 / 下一首 /
  音量 / 循环。音乐只从本机读取，**不上传服务端**；列表记在本机，下次打开不自动播放。
- **后台一键清理**（管理员）：后台「概览」页可按阈值预览并清理无用房间 / 无用账号，
  先预览核对再执行；执行前需输入确认词。

## Windows

解压到任意目录（**建议纯英文路径**），双击 `werewolf_app.exe`。
首次进入「服务器设置」，填：

- 本机自测：`https://localhost:11111`
- 局域网：`https://<服务端内网IP>:11111`
- 公网：`https://你的域名:11111`

保持「允许自签名证书」开启（自签证书场景必须；换成正式证书后可关掉）。
点「测试连接」通过后再「保存并进入」。

## Android

把 APK 传到手机安装，需要允许「未知来源」。

> ⚠️ 当前是 **debug key 签名**（`CN=Android Debug`），只适合自用侧载。
> 要上应用商店或做正式分发，需要另建 release keystore 并在
> `android/app/build.gradle` 的 `signingConfigs.release` 里配置，然后重新构建。

麦克风语音需要运行时授权，首次点麦会弹权限框；服务端语音微服务未启动时，
对局里的语音入口会自动隐藏（由 `game.state` 的 `voiceAvailable` 决定）。

## Linux

两个包都由 GitHub Actions 在 **ubuntu-22.04** 上构建（glibc 2.35），可在 22.04 及更新的
发行版上运行；更老的发行版（如 20.04）因 glibc 偏旧可能跑不起来。

### deb（Debian / Ubuntu）

```bash
sudo apt install ./狼人杀客户端-1.4.0-linux-x64.deb
werewolf-client            # 或从应用菜单点「狼人杀」
```

依赖会自动安装：GTK3 + GStreamer 运行库（`libgstreamer1.0-0`、
`libgstreamer-plugins-base1.0-0`、`gstreamer1.0-plugins-good`）。最后一项是**音频**所需——
对局音效与背景音乐都走 GStreamer 播放运行时，缺了它会静音。

### 便携版（任意 x64 Linux）

```bash
tar xf 狼人杀客户端-1.4.0-linux-x64-portable.tar.xz -C ~/ww
~/ww/werewolf_app
```

> 连自签证书的局域网服务端时，App 内「服务器设置」里保持"允许自签名证书"开启即可
> （Dart 侧 `HttpOverrides` 放行，不依赖系统 CA）。

## Web

解压 `狼人杀客户端-1.4.0-web.zip`，把里面的文件放到任意静态站点根目录即可
（Nginx / Apache / GitHub Pages / 对象存储都行）。

- 必须整目录部署，不能只拷 `index.html`：`main.dart.js`、`assets/`、`canvaskit/` 都是运行依赖。
- 浏览器自己处理 TLS，所以自签证书由浏览器弹「继续访问」，客户端里不需要「允许自签名证书」。
- 自定义背景在 Web 上只保留当前会话（浏览器不给本地路径，刷新后回默认）。
- 导出 CSV 会走浏览器下载，不再弹保存对话框。

## iOS

`狼人杀客户端-1.4.0-ios-unsigned.zip` 里是**未签名**的 `Runner.app`（CI 上没有证书）。
要装到真机或上架，需要：

1. 在 macOS 上用 Xcode 打开 `ios/Runner.xcworkspace`；
2. 在 `Signing & Capabilities` 里选自己的 Team（Bundle ID 按需改）；
3. 或用 `codesign` 对 `Runner.app` 重签后再打包成 IPA。

首次发言会请求麦克风权限；连接局域网服务端会请求「本地网络」权限，两者都已在
`Info.plist` 里写好用途说明。

## 与旧客户端的关系

- **Electron 套壳（`G:\wwelectron`）已停用**：它加载网页版，体积大且**做不到安卓**，
  五端目标下不再构建分发。保留目录仅作历史参考（其服务器地址已由并行会话改到 11111）。
- **Capacitor 方案（`G:\wolfmobile`）作废**：与 Flutter 方案目标重叠，且桌面侧能力弱。
- **网页版 / PWA 继续保留**：它和客户端连的是同一套 `/api` + `/ws` 接口，
  互相之间天然互通，仍是最省事的入口。

## 出问题先看这里

- 连不上：确认服务端在跑（`https://<地址>:11111/api/health` 应返回 `{"ok":true}`），
  以及「允许自签名证书」是否开着。
- 安卓装不上：机型是 arm64 却装了 arm32 包（或反之），换一个包试。
- iOS 装不上：未签名包不能直接安装，按上面 iOS 一节重签。
- Web 打开是白屏：确认是整目录部署（缺 `main.dart.js` 或 `canvaskit/` 会白屏），
  并检查浏览器控制台的 404。
- 语音没声音：服务端语音微服务（SenseVoice + Kokoro）要起来；
  App 侧的判定来自 `voice.hello` 的 `enabled`。
- 背景音乐没声音：确认选的确实是本机 `.mp3` 文件、文件没被移动或删除
  （BGM 记的是本机路径，不是拷贝副本）；Linux 上还需装上面的 GStreamer 依赖。
- 界面还是中文：语言在 🌐 按钮里选，选完立刻生效；对局内的身份名 / AI 发言 / 昵称
  属内容文本，按设计不参与翻译（与网页端一致）。
- 3D 视角卡顿：手机端低端机型可在对局页再点一次 3D 按钮切回 2D 座位条；
  3D 已按 30fps 上限运行，且会随距离自动裁掉亚像素小面。
- 3D 视角里看不到自己/看不清角色：右下角点「近景」，镜头会自动推到当前发言者并让他转身面向镜头。

### 自己重新出包

`.github/workflows/client-release.yml` 会一并产出五端：推一个 `v*` tag 即触发，
各平台在官方 runner 上构建（Linux 在干净 `ubuntu:22.04` 容器里，iOS 在 `macos-14` 上，
Web 先 `flutter config --enable-web`），打 tag 时自动汇总成 Release 附件。
也可在 Actions 页手动 Run workflow。
